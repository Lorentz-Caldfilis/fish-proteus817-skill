# 通用 Skill 设计规范

基线日期：2026-10-27。适用于本轮源代码、版本适配、DSH 工具、验证和交付。架构见 [ARCHITECTURE](ARCHITECTURE.md)，能力门槛见 [ROADMAP](ROADMAP.md)。

## 规范用语和证据

“必须”是验收约束；“建议”是可按实际证据调整的实现偏好。文档中的设计接口不是已实现接口，实现状态必须单独登记。用户需求、资料事实、推断、计算预期、原始观测和通过结论分开；参考代码或作者日志不代替本机复现。

成功分层为 `prepared`、`file_verified`、`native_verified`、`runtime_observed`、`runtime_verified`；`blocked`、`unsupported`、`failed` 保留具体阶段和原因。不能把 JSON schema 通过、程序退出码 0、SDF 存在、软件打开或模型 final 单独当行为成功。

## 公共 API 与工具合约

1. 采用有类型、可组合的操作，参数说明包含单位、前置状态、返回值、副作用和失败条件。公开调用不依赖研究脚本私有方法。
2. 元件、引脚、网络、会话、工程、固件和证据使用明确身份；查得的引脚定义优先，禁止按显示数字或相邻坐标猜连接。
3. 所有修改携带工程 revision/源身份；在已打开或改变的源上继续编辑必须重读，陈旧修改拒绝提交。
4. 统一响应包含 request/task/circuit/session 标识、状态、数据、实际副作用和证据引用。错误区分输入错误、不支持、前置状态不满足、兼容失败和观测不符。
5. DSH 工具只接受固定领域操作与结构化参数。任务边界由宿主固定；模型不能指定任意进程、Python、库、shell 或环境变量。扩充语义能力不以开放通用执行器替代。
6. 单线程/单会话串行执行；重试必须针对可恢复原因并有上限。状态改变的命令重复执行前确认是否已生效，不能因超时无限重放。

## 数据与工程操作

1. 本机安装资料、原始课程资料和导入库只读，编辑发生在独立工作副本。新目标默认不得覆盖，显式更新仅限当前受管任务，保留恢复点。
2. 新建、打开既有工程、原生属性修改是不同路径。不能为绕过未知结构拒绝而将既有工程换成空白构造器。
3. 原子保存先生成临时文件，验证容器/记录/引用/计数/范围，确认源未变化后提交。不能仅修 ZIP CRC 而忽略 DSN/CDB 对象引用和目录偏移。
4. 增删、改名、移动、复制、旋转、镜像、断线等操作保持幸存支路/共享结点、标签、端子和定义一致。无关未知成员不得静默删除。
5. 位置单位、旋转和镜像语义显式。布局至少满足文本与器件不严重遮挡、引脚确实接到端点、正交路径可追踪；没有避障算法时明确能力限制，不把网表正确当视觉布局合格。
6. 新增器件必须来自已核实定义或合法本机库，不生成虚构引脚/模型。查询、导入、结构支持和仿真支持分开报告。

## 会话、兼容和仿真

1. 识别目标为产品版本、实际文件构建和模块哈希组合。文件格式能力与内存/交互能力分别判定，不因主版本相近直接兼容或全部拒绝。
2. 只管理自有 PID，核对可执行路径、项目、进程创建时间和窗口。不得按进程名终止用户其他实例；超时清理只处理确切自有进程和本次创建的临时目录。
3. 内部对象适配必须给出字段来源和本机构建验证；只增加 8.17 哈希或移除旧指纹检查不算适配。只读检查对象时不改应用 DLL、许可证、模型或系统策略。
4. 文件层、属性导入、原生保存、仿真执行互斥。控件绑定检查全部键槽冲突，在保存重开后测试，同一响应测试期间不重启仿真。
5. 定时请求、实际开始/结束时间、容差、超出量和 completion 分开。墙钟预算只约束等待/超时，不代替仿真时间；false/null 不得被计算预期补齐。
6. GPIO 事件、按钮机械状态、逻辑输入、引脚电压和 LED 显示是不同观测。按下指令已提交不表示固件已响应；必须继续仿真并读取下游输出。
7. CSV/图表测量必须绑定本次工程、参数、分析与重新计算，处理旧缓存；`simulate=false` 不能用作新仿真证据。采样时间、单位、插值方法和误差要可追踪。
8. 跨语言JSON不得损失进程身份精度。超JavaScript安全范围的整数字面量使用原十进制字符串传输，不先转Number；Python原始整数及自有PID校验不变。stdout原字节、编码和hash留本地，模型仅接收最小化语义；CLI镜像截断不能替代完整本地证据，也不能据此推断模型上下文被截断。

## 测试规范

测试按实际行为和重要边界设计，不为 README 文案、内部调用顺序或实现的重复表达而写测试。离线测试使用原创合成 fixture；真实安装/器件定义/官方样例仅作私有输入。

覆盖四层：模型/解析/参数离线检查；原生重开/SDF 结构检查；时间/交互/电气行为；DSH 自然语言完整流程。新增能力和每次兼容修复有对应最小回归；通过后仅在新变化或未解决风险需要时扩大/重复测试。

至少留一项非预置拓扑任务，不能使用后端硬编码该任务的完整电路作为“通用”证明。期望由独立规格或数学模型得出，不能由测量器自行写入预期值。所有运行保留实际 source/build/project/firmware/raw-data 身份。

## Skill 文档和版本

入口只保留目的、关键约束、任务路由和失败报告；精确方法签名、参数、工作流、证据规则放按需 references。名称、描述、license、compatibility 和字符串 metadata 遵守 Agent Skills 规范。工具文档与实际 schema 同步，不能描述尚未实现功能为可用。

版本采用可追踪发布，保留 0.1.1 回归点。接口包、Skill、能力配置和发布白名单版本一致；允许开发阶段有未完成状态，但不得把版本号或通过率当作能力达成证据。

## 依赖、许可和公开分发

复用教师参考库的 MIT 原创代码必须保留来源、提交和许可，说明修改；不把原软件/官方样例/器件定义/提取固件/课程图纸视为 MIT。其他 EDA 仅借鉴思想。依赖放项目隔离环境，不改用户全局配置。

上游 source commit、当前 wheel、已安装模块和历史原生报告分别绑定身份。上游发布清单存在 `source_and_all_installations_match=false` 及历史 native_reports 所属 previous wheel 的说明，不能将其合并为本次发行证据。vendor 清单保存原文件 Git blob/hash、固定来源和本地修改后 hash；原私有目录的七个不完整/已修改研究文件不能当作完整原版依赖。

公开发布继续采用显式文件白名单、全新源码树、包成员/哈希检查和已知凭据原值检查。原始图纸、接线图、截图、完整会话、用户路径和旧私有历史不随包公开；不能因功能完成自动改变仓库可见性或破坏既有历史。
