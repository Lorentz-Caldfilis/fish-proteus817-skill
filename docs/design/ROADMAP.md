# 设计路线、进程和能力验收

基线日期：2026-10-27。目标是达到参考项目受支持能力在本机 8.17 SP2 上的同级实现和实测证据；增加固定课程模板、仅写接口说明或忽略兼容失败不满足完成条件。

实现进展（2026-10-27）：实际库目录56785项；13份结构案例均通过原生SDF、Save后Codec重开及原件保护，另通过原生ADI改属性→保存→文件续改→原生网表。数值时钟0.01/1.25秒相对推进、实际浮点残余暂停分支、ELF/HEX身份与STM32固件、六控件各自的GPIO 0→1→0及三份CSV幅值1→2重算均有本机证据。四种被动开关采用显式ADC+BUFFER接口；直接模拟接入未响应的限制保留。旧TLS诊断不删除。目录示例U1/U2标题已移离COM/PD0并完成原生及目视复核，不改变拓扑。

安装验收：早期 115 文件干净候选 wheel 完成代表性原生验证后，0.2.0 最终 wheel 亦实际重新安装，并在全新venv的`-I`隔离解释器完成单独原生验收；模块来自site-packages且与最终公开源hash一致。三路网络保存重开、五控件绑定及操作/幂等、单路原创GPIO、reset停止与新CSV通过。重建发行仍分别保留新包哈希与实际安装验收；五路同时GPIO、reset后restart及跨构建兼容未测，不扩写为已支持。

G13：用户明确同意具体派生数据外发后，真实DSH续段19请求/100事件/exit0，在与文件设计相同task的另一会话完成闭环。PID44636的三段请求均为0.15秒/容差0.003秒，实际0.1525、0.15、0.15秒，最终原生时钟0.6525秒；PA5为0@0.002559、1@0.352524、0@0.502519。初次时间断言误用run_for子序号而失败，改为完整steps索引5/9/13后通过。最终七项混合断言全过，总状态按最弱依据为native_verified，单项时间/GPIO为runtime_verified；没有调整规则。独立审计核验raw字节、原生网表、固件/工程身份、逐时钟GPIO前缀及正常关闭。

## 最小真实任务组合

1. 结构组合：从实际库查询器件，创建非三课程模板的新拓扑，逐项增删改/移动/旋转/改名，保存重开并比对原生SDF；含六路网络、端子、电源、标签和既有图保留。
2. 数字交互：合法官方STM32样例的独立副本/器件定义和原创固件，六类控件分别测试，按钮输入—固件—输出的同Session三阶段响应，实际时间记录。
3. 模拟测量：合法官方RC图表副本，变输入幅值后清缓存重算，用CSV独立比较电压、电流和波形；不以截图或解析成功代替仿真。
4. DSH闭环：用户只给规格，模型查询器件/引脚并组合工具形成计划，不给完整成品拓扑程序；执行后交付可编辑工程、结构/运行证据与限制。
5. 回归：保留三类8086流程。通用代码变化后先运行受影响离线测试；运行适配变化则再测受影响真实场景，不无依据反复重跑全部矩阵。

## 进程记录与停止条件

每阶段记录实际工作、文件、构建/模块身份、执行结果、失败及兼容修复；阶段门槛通过才更新状态。现场失败按输入/格式/库路径/模型/窗口状态/对象布局/观测七类定位，最小修复后回归；只读/错误参数失败不转成成功。

无法取得所需模型/合法资源、格式存在无法安全保留的未知对象、内部布局尚不能独立核验、或者测量接口缺证据时，保留阻断并继续独立模块研究。不得通过破坏原件、变更系统策略、伪造观测或任意关闭版本保护完成验收；若需要用户提供本任务外资源或新授权，再给出具体可审阅问题。

最终交付必须包含能力状态表、源码/Skill、使用与精确接口文档、真实本机证据、已知边界、干净源码树/包及原私有历史保留说明。私有代码阶段使用独立开发分支，发布不自动切换仓库可见性。
